# 各種登退場アニメーション  

登場と退場を指定した時間で行うスクリプト。  
すべて「切り替え効果」の所に表示されるようになっています。  

導入方法:  
「@各種登退場_AKIRA.anm2」  
「easing.lua」  
「entry_helper.lua」  
「AKIRA_aviutl2_helper.lua」  
の4つのファイルを  
C:\ProgramData\aviutl2\Script  
もしくは、  
C:\ProgramData\aviutl2\Scriptの直下のフォルダ  
に入れてください。  
要約すると、通常のスクリプトと同じで、ただファイルの数が4つになっただけです。  

内容:  
発光登退場_AKIRA  
クリッピング登退場_AKIRA  
波紋登退場_AKIRA  
ラスター登退場_AKIRA  
モザイク登退場_AKIRA  
画像ループ登退場_AKIRA  
色ずれ登退場_AKIRA  
振動登退場_AKIRA  
震える登退場_AKIRA  
横からキラリ登退場_AKIRA  
斜めからキラリ登退場_AKIRA  
モザイク登退場_AKIRA  
グロー登退場_AKIRA  
放射ブラー登退場_AKIRA  
方向ブラー登退場_AKIRA  
レンズブラー登退場_AKIRA  

各種スクリプト名に「_AKIRA」とついているのは、これがついていないとスクリプト名が被ってしまうかもしれない、との懸念から作成者の名前を記載しております。  
それ以外の理由はなく、特に拘りなどもないため改変等を行う場合、適宜変更していただいて構いません。    

**二次配布可、改変可、クレジット不要**
